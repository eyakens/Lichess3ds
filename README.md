# Lichess3ds
Lichess client for 3ds with support of crossplatform online using api 

Full compatible with old 3ds and new 3ds

AI was used to create this homebrew

Instruction

3dsx
1. Put 3dsx file into sdmc:\3ds
2. Launch Lichess3ds from homebrew launcher

cia
1. Put cia into sdmc:\cias
2. Use fbi or 3dsDL to download it
